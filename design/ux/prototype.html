UX redesign · progressive disclosure

One screen, one main action.

Prototype for design/ux/UX-REDESIGN.md. Each frame is a real state of the wizard. Rule: one primary action per screen, 3–5 visible primary controls, everything else behind a labelled disclosure, menu, tab or dialog — and every collapsed thing shows its current value.
